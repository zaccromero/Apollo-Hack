Before you begin

A little clarity
goes a long way.

Does Apollo use real money?

No. Apollo is an educational game with simulated orders and a paper portfolio. It provides no real-money trading, brokerage account or personalized investment advice.

Is the website example the actual app?

Product images are labeled actual app captures. The website lesson is fictional and separate from the app. It never changes your app account, and it resets on reload. The video opening records this website simulation; later footage retains its original app and Simulator labels.

How should I read the data?

Check the source, date and limits of each item. Demo prices and teaching illustrations are separate from sourced research. Paper results are simulated and don’t predict real returns.

Can I download the iPhone app?

The public beta link isn’t available here yet. This page will show an install link and matching QR code once access to the current Apollo game is verified.
