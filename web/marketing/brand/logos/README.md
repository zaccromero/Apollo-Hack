# Apollo logo v1

Proposed logo for owner review, October17,2026. The sun and green/lime/cream palette extend the actual Apollo app and marketing direction. The lowercase wordmark uses outlined Avenir Next Heavy glyphs with tightened spacing. SVG files contain actual paths: no webfont, font download, external asset, script or image-generation service is required.

- apollo-logo-dark.svg / .png: lime sun + cream wordmark, transparent, for dark backgrounds.
- apollo-logo-light.svg / .png: all ink, transparent, for light backgrounds.
- apollo-logo-white.svg / .png: all white, transparent, for single-color reverse use.
- apollo-logo-preview.png: presentation of dark and light treatments; use production transparent assets for placement.

SVG artboard999×300; transparent PNG2997×900. Keep the full artboard’s clear space. Scale proportionally; do not add returns arrows, gradients, effects or a slogan inside the lockup. Use the existing standalone sun/app-icon for square contexts. This logo does not replace the iOS asset catalog or the frozen marketing v1 source. Adoption remains an integrator/owner decision.

Build method: local vector paths from CoreText plus the existing sun concept; raster exports rendered from those same paths. No paid calls or new credits. Opaque preview and transparent exports visually inspected. No website or release gate was reopened for this additive logo delta.
