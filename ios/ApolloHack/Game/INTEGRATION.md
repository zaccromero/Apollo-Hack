## Service contract

See ApolloGameModels.swift. Native Decimal models are mapped from decimal JSON strings by the integration adapter. Service is @MainActor, async throws. `catalog`, `account`, `record`, `preview`, `previewCopy`, `confirm`, `reset` are the complete protocol. Do not silently replace service failures with demo success.

`thesis` String carries JSON from ApolloThesis `{reason,risk,invalidation}` for preview and paper fill. Decode it to the backend structured thesis object. ApolloThesis.display renders structured or legacy strings.

ApolloAsset `quoteAsOf`, `quoteStale`, `quoteProvenance`, `evidenceTracks` have default values. Populate from research. Each ApolloEvidenceTrack has topic, status, summary, sources. Preserve unknown/unverified rather than manufacture scores. Three tracks render separately: earnings/fundamentals, leadership/governance, trends/sentiment.

ApolloOrderPreview `quoteProvenance` and `warnings` render separately in confirmation. Populate actual PAPER execution provenance even when research card price differs. Preview lines/total are authoritative for confirmation; account returned by confirm is authoritative for holdings. An interest gesture records interest and opens a form; only explicit confirmed preview calls confirm. Cancellation does not create a fill. Reset UI has a destructive confirmation; network service must implement backend reset preview and confirm.
